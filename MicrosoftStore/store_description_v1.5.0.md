## What's new in v1.5.0.0
- **Interactive Donut Chart**: Added a dedicated Donut Chart tab visualizing disk space distribution across top folders with Fluent accent colors, center total size display, and click-to-drill-down navigation.
- **Top 100 Largest Files Tab**: Added a dedicated "Top Files" tab with multithreaded scanning and early pruning that surfaces the 100 largest files across the entire drive, including root-level system files.
- **Large & Old Files Quick Filter**: One-click toolbar toggle filter button to instantly isolate files larger than 100 MB not modified in 12+ months, complete with a live match count badge.
- **Send to Recycle Bin**: Added a right-click context menu action in the results grid to safely send files or folders to the Windows Recycle Bin with a confirmation dialog.
- **Command Palette Settings**: Replaced placeholder settings with native Command Palette Settings integration, providing toggles for "Show Hidden Files" and "Max Scan Depth".
- **Command Palette Asynchronous Loading**: Command Palette queries now run asynchronously in the background, eliminating UI freezes and maintaining responsiveness during large drive scans.
- **Visual Bar Chart Improvements**: Bar chart now dynamically scales with the window and supports horizontal scrolling for comprehensive viewing without clipping.
- **Modernized Help Page**: Fully refreshed Help and Features guide detailing Donut Charts, Top Files, Old & Large filtering, Recycle Bin integration, and Command Palette shortcuts.
